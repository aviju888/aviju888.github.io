Project 1

Colorizing the Prokudin-Gorskii Photo Collection

This project focuses on colorizing historical black-and-white images by aligning RGB color channels. The approach involves splitting film strips into red, blue, and green channels, then using alignment techniques including normalization, pyramid-based methods, and white balancing to create realistic colorized versions of the original photographs.

Project 2

Fun with Filters and Frequencies

Exploring image processing through various filters and frequency domain techniques. This project covers edge detection, image sharpening, hybrid images, and multi-resolution blending using Gaussian and Laplacian pyramids. Learn how different frequency components affect image perception and how to manipulate them for creative effects.

Project 3

Face Morphing

Implementation of image morphing techniques to create seamless transitions between images. The project involves establishing correspondence points, applying affine transformations, and generating intermediate frames. Includes creating mid-way faces, morph sequences, and computing mean faces from population data.

Project 4

Stitching Photo Mosaics (Panoramas)

Creating panoramic images by stitching multiple photographs together. This project explores feature detection, image matching, homography estimation, and image warping techniques. Learn how to automatically detect and match features across images to create seamless panoramic compositions from multiple viewpoints.

Project 5

Diffusion Models

Exploring diffusion models through sampling, denoising, and translation techniques. This project covers the forward process of adding Gaussian noise, classical denoising methods, and model-based approaches. Implement and compare different denoising strategies while understanding the principles behind modern generative AI models.

Final Project Part 1

HDR Images

High Dynamic Range (HDR) imaging techniques for capturing and processing images with extended luminance ranges. This project covers exposure bracketing, tone mapping, and methods for combining multiple exposures to create images that better represent the full range of light in a scene, from deep shadows to bright highlights.

Final Project Part 2

Light Field Camera

Exploring light field imaging capabilities through depth refocusing and aperture adjustment techniques. Using multiple images captured over a grid orthogonal to the optical axis, this project recreates complex photographic effects through computational operations like shifting and averaging, demonstrating the power of computational photography.
