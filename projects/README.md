# CS180 Projects

This directory contains all CS180 computer vision projects, each organized in its own subdirectory.

## Project Structure

Each project follows this structure:
```
projN/
├── code/          # Source code for the project
├── data/          # Input data and images
├── output/        # Generated outputs
└── web/           # Web pages and assets for viewing the project
    ├── index.html # Main project page
    └── images/    # Web-specific images
```

## Projects

3. **proj3/** - Face Morphing
4. **proj4/** - Stitching Photo Mosaics (Panoramas)
